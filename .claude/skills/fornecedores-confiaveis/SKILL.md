# Fornecedores

Confiáveis"**, https://youtu.be/ESt3C_ZV1AA

## Químicos aromáticos — os três confiáveis

| | observação |
|---|---|
| **Perfumístico** (Márcio) | confiança total. Só compra de fornecedor idôneo, tem material da IFF. Trabalha sozinho, então **demora alguns dias a uma semana** para enviar. Resolve qualquer problema: troca ou devolve. |
| **Flavorist** (Fabrício) | vem do atacado industrial; o varejo é o excedente. Por isso **nem sempre tem cromatografia disponível**. Criteriosos com qualidade. |
| **Eu Perfumista** | **a mais cara das três**, mas só traz produto de altíssimo nível. |

## Óleos essenciais naturais — três especialistas

Estes **não estão mapeados no app** (que raspa Flavorist, Perfumoteca,
Perfumístico, EuPerfumista e Neuroaroma):

1. **Harmony** — primeira escolha
2. **Laszlo** — segunda
3. **Fitoterápica** — **com ressalvas, último caso**

## Por que adulteração importa mesmo indo de sintético

O projeto do usuário segue a regra do **máximo sintético**, o que reduz muito a
exposição. Mas onde o óleo essencial é inevitável (no catálogo atual, só o
gengibre), o risco é real:

- o cheiro não é o que a fórmula supõe, e o resultado não reproduz
- **alergia**: boa parte das reações atribuídas a óleo essencial vem de
  adulterante, não do óleo
- diluir um óleo já adulterado multiplica o erro

## Regra prática

Se o material tem equivalente sintético que preste, o sintético resolve
qualidade, lote e preço de uma vez — ver a política de máximo sintético em
`web/lib/alvos.ts`. O óleo essencial fica para onde não há substituto.
